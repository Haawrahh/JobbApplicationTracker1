# JobbApplicationTracker

## Av : Hawo Raage (datum: 2025-10-19)

## Syfte : är att träna på OOP, LINQ och github.

## Funktioner 
- Lägga till en jobbansökan
- Visa alla jobbansökningar
- Söka efter en jobbansökan baserat på företagets namn
- Uppdatera status för en jobbansökan
- Ta bort en jobbansökan
- filtrera och sortera med LINQ

## Teknik som används 
- C#
- .NET 8.0 
- Konsolapplikation
- Objektorienterad programmering (OOP)
- LINQ (Language Integrated Query)
- GitHub för versionshantering commits, pull requests

## Hur hjälpte LINQ i detta projekt?
LINQ användes för att effektivt filtrera och sortera jobbansökningar baserat på olika kriterier som företagets namn, ansökningsdatum och status. Det gjorde koden mer läsbar och underlättade hanteringen av samlingar av objekt.

## Vilket del av projektet tyckte du var mest utmanande och varför?
Det svåraste var att använda LINQ för att filtrera och sortera jobbansökningar på ett effektivt sätt. Det krävde en djupare förståelse för LINQ.
